# Sun Global Financial Services — Homepage

## Files
- index.html — page structure and content
- styles.css — responsive visual design
- script.js — mobile navigation, active navigation state and demo form interaction

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before production
1. Replace the temporary image URLs with approved Sun Global photography.
2. Replace placeholder social links and legal-policy links.
3. Connect the consultation form to the actual lead destination (email, CRM, API, etc.).
4. Confirm the final public address and company registration details.
5. Have the final financial-services disclosures reviewed before publishing.
6. Confirm permission to display provider logos/names.

The page uses Google Fonts and remote Unsplash images for the visual prototype.
